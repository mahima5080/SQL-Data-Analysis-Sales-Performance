# SQL for Data Analysis — Data Analyst Week 2 Project

## 📌 Project Overview
This repository contains the **SQL Analysis Queries** for a retail sales dataset. It answers core business questions regarding top-spending customers, average order values (AOV), category breakdowns, order tiering, and regional sales performance.

---

## 🛠️ Key SQL Queries Included
* **Top Customers**: `SUM()`, `GROUP BY`, `ORDER BY`, `LIMIT`
* **Average Order Value (AOV)**: `AVG()`, `ROUND()`, `COUNT()`
* **Category Performance**: Aggregated sales and order volume per category
* **Conditional Tiering**: `CASE WHEN` logic to segment high/low value orders
* **Regional Breakdown**: `SUM()` total revenue per region

---

* **Average Order Value**: $12,100.53
